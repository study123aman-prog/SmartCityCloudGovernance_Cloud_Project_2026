# Legacy AWS Infrastructure & Reference Configurations

This directory contains previous AWS deployment scripts, CloudFormation templates, and Lambda report generators archived for future cloud integration reference.

The core **FireGuard AI** application runs 100% locally and does not depend on any files in this directory.

Refer to [docs/aws-integration-guide.md](../../docs/aws-integration-guide.md) for instructions on integrating AWS services (IoT Core, DynamoDB, S3, SNS, CloudWatch) with the new repository and service abstractions.
