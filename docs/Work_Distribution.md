# Repository Workflow

```
main
   ▲
   │
develop
 ┌──────┼────────┐
 │      │        │
 │      │        │
feature/ feature/ feature/
aman-    Aditya_  jain_
singh    upadhye  shaab
```

Each member:
1. Works only on their assigned feature branch.
2. Commits changes regularly.
3. Pushes updates to GitHub.
4. Creates a Pull Request to `develop`.
5. Participates in code and document review.
6. After approval, changes are merged into `develop`.
7. Once all tasks are completed and verified, `develop` is merged into `main`.
